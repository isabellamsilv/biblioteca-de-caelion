# Ensaios

**Pergunta central:** o que amadureceu em mim até se tornar uma posição?

Os ensaios serão textos autorais completos. Eles podem nascer de um estudo, mas não funcionarão como resumos de pesquisa: terão argumento, voz, forma e responsabilidade pelas conclusões que propõem.
